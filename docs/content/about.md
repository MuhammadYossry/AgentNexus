# About AgentNexus

AgentNexus is an open-source Python library for building AI and LLM agents with interactive UIs and structured workflows. We focus on simplifying agent development through declarative syntax and automatic manifest generation.

## Project Goals

- **Simplify Agent Development**: Reduce boilerplate with intuitive decorators
- **Standardize Agent Communication**: Define a common protocol for agent discovery and interaction
- **Enable Rich UI Interactions**: Provide a comprehensive UI component system
- **Support Complex Workflows**: Build multi-step agent interactions with state management

## Development Status

AgentNexus is currently in alpha stage. While we're actively developing the library, it's not yet recommended for production use.
